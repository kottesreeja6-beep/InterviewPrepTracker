# Interview Preparation & Job Application Tracker

A web application built using Python and Flask to help students organize job applications and prepare for interviews.

## Features
- Add, view, edit, and delete job applications
- Track application status: Applied, Interview, Selected, and Rejected
- Record interview dates and times
- Save and manage interview questions and answers
- View application and interview counts on the dashboard
- View technical skills

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the required packages:

   `pip install -r requirements.txt`

5. Run the application:

   `python app.py`

6. Open `http://127.0.0.1:5000/` in your browser.

## Project Purpose
This project helps students manage job applications and organize interview preparation in one place.
